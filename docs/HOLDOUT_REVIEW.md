# M01 독립 보류 시험 60건 검토 방법

`HOLDOUT_DRAFT.tsv`는 개발자가 2026-10-20에 작성한 **가상 초안**이다. 40건은 M01 관련 설명, 20건은 조건 부족·범위 밖 설명으로 임시 분류했다. 실제 학생 발언과 교사 검수 자료가 아니다. 기존 개발 예시 E1~E6의 문장이나 숫자만 바꾼 복제 문장은 사용하지 않는다.

교사는 초안을 아이디어 참고용으로 보고 **독립적인 문장을 직접 작성하거나 재작성**한다. 원문 그대로 승인하면 PRD의 ‘교사 작성·검토’ 조건을 충족하지 않으며 평가 도구도 같은 문장·숫자만 바꾼 문장을 거부한다. 별도 TSV 파일에 실제 학생 이름, 발언 원문, 학번, 연락처, 개인 사정을 넣지 않는다. `cohort=related`인 항목에는 교사가 허용하는 탐구 카드 ID(A/B/C)를 `A|B`처럼 적는다. `cohort=hold`는 `allowedCards`를 비워 둔다. `highRisk`는 반대 의미·부정·전체 조건 변화처럼 부적절 추천의 위험이 큰 항목에 `yes`로 둔다. 검토가 끝난 항목만 `reviewStatus=approved`로 바꾸고, 판단 근거를 `reviewNote`에 남긴다. 이 필드만으로 실제 사람의 검수를 증명할 수는 없으므로, 최종 검수 확인은 별도로 받아야 한다.

평가 도구는 **60건 전부** 승인 상태이고 관련 40건·보류 20건의 구성, 중복·길이·개발 예시 중복, 허용 카드 지정이 맞을 때만 실행한다. 초안 파일은 의도적으로 거부한다. 교사 판단을 보기 전에는 임계값을 이 파일로 조정하지 않는다. 한 번 평가에 사용한 자료로 임계값을 바꿨다면 그 자료는 더 이상 독립 보류 시험이 아니며 새 자료를 마련해야 한다.

로컬 정적 preview를 켠 뒤 PowerShell에서 다음을 실행한다. 경로는 실제 검수 파일로 바꾼다.

```powershell
$env:TEST_URL='http://127.0.0.1:4173/qa-forks/'
npm run test:holdout -- 'C:\path\to\teacher-reviewed.tsv'
```

도구는 실제 브라우저의 로컬 모델로 질의를 평가하고 데이터셋 SHA-256, 관련 40건의 AI·키워드 첫 추천 적합률, 보류 20건의 추천 억제율, 고위험 항목의 보류 또는 허용 후보 여부, 준비 후 요청 지연 p95를 **집계로만** 출력한다. 원문 질의·개별 응답을 출력 파일에 저장하지 않는다. 후보가 총 3개뿐인 top3 포함률은 AI의 추가 가치 증거로 사용하지 않는다. `reviewStatus`는 파일의 자기 선언이므로 도구 결과를 교사 검수 완료 증거로 단독 사용하지 않는다.

`npm run test:ai`는 기존 개발 예시 2건으로 실행 경로만 확인하는 기술 smoke 시험이다. 독립 보류 시험이나 추천 품질 평가로 보고하지 않는다.
