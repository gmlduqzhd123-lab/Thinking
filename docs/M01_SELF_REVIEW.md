# M01 개발자 자체 검토 · 2026-10-20

이 기록은 현재 코드와 자동 시험을 대조한 **개발자 자체 검토**다. 교사의 교육적 승인, 독립 AI 품질 시험 60건, 학교 기기 검증, 실제 수업 관찰을 대신하지 않는다. 콘텐츠 상태는 개발용 초안으로 유지한다.

| 대상 | 개발자 확인 결과 | 교사 판단 |
| --- | --- | --- |
| 첫 선택·재선택 | 모두 `M01-UF-01` 버전 1, 같은 전체의 `1/3` 대 `1/5` | 미검수 |
| 선택지 | A/B/C와 `D. 모르겠다`를 별도 집계, 미응답은 참여 인원에서 집계 합계를 빼서 표시 | 미검수 |
| 이유 카드 | 3개 중 교사가 고른 탐구 주제만 기록, 학생 개인의 생각으로 단정하지 않음 | 미검수 |
| 기본 탐구 1~3 | 같은 전체의 `1/3`·`1/5`, `1/4`·`1/8`, 조절 가능한 `1/3`·`1/2~1/12` 막대 | 미검수 |
| 개념 정리 | 교사가 공개 버튼을 누른 뒤 `1/3 > 1/5`와 ‘같은 전체에서 더 많이 나누면 한 조각이 작다’ 표시 | 미검수 |
| 새로운 문제 | 별도 `M01-UF-02` 버전 1, 같은 전체의 `1/4` 대 `1/6`; 설명은 교사 버튼으로 공개 | 미검수 |
| 메모리 요약 | 선택한 이유 카드·집단 집계만 표시. 10/20→15/20은 `+25.0%p`로 계산하며 개인별 성장이라 하지 않음 | 미검수 |

수학 확인: 같은 전체라면 `1/3=5/15 > 3/15=1/5`, `1/4=3/12 > 2/12=1/6`이다. 2~12등분 SVG는 모두 같은 600단위 전체를 사용한다. `npm test`의 분할 경계 시험과 공개 수업 흐름 브라우저 시험으로 구현을 확인했다. 이 수학 확인은 문장 난이도와 교실에서의 이해도를 보증하지 않는다.

자체 검토 중 **요약 누락 오류**를 발견했다. 이유 카드 선택이 최종 요약에 나타나지 않았고, 선택 수정 뒤에도 기존 요약이 남을 수 있었다. 수정 전 공개 브라우저 회귀 시험이 실패했으며, 수정 후 선택한 카드를 ‘교사가 고른 탐구 주제’로만 표시하고 변경 시 요약을 무효화하도록 고쳤다. 학생의 실제 생각을 추정하는 문장은 넣지 않았다.

교사가 판단해야 할 내용은 ① 용어와 질문이 해당 학년 수준에 적합한지, ② 세 탐구가 실제 교실에서 충분한지, ③ 이유 카드·정리 문구에 오해의 여지가 없는지, ④ 실물 교사 PC와 TV에서 읽고 조작하기 쉬운지다. 이 네 항목은 현재 모두 **미검수**다. 개발자 작성 `HOLDOUT_DRAFT.tsv`는 독립 교사 시험 자료로 승격하지 않는다.
