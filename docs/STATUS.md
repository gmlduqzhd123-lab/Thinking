# 배포 및 기능 현황 (v1.0.0)

- **버전**: v1.0.0 정식 릴리스
- **배포 주소**: `https://gmlduqzhd123-lab.github.io/Thinking/` (및 `https://gmlduqzhd123-lab.github.io/Thinking/lesson.html`)
- **지원 단원**:
  - `M01 · 단위분수 비교` (1/3 vs 1/5, 전이 1/4 vs 1/6)
  - `M02 · 단위분수 심화 비교` (1/4 vs 1/7, 전이 1/5 vs 1/8)
  - `M03 · 단위분수 응용 비교` (1/2 vs 1/6, 전이 1/3 vs 1/8)
- **주요 완료 기능**:
  - 10단계 탐구 수업 흐름 (`개념` → `미리보기` → `첫 선택` → `이유` → `탐구 1~3` → `정리` → `재선택` → `새 문제` → `요약` → `종료`)
  - 막대(리본) 모형 및 원형(피자) 모형 전환, 첫 조각 비교 기준선 표시
  - 탐구 3단계 양방향 분모 조절 및 실시간 크기 비교 부등호 배지
  - 이유 카드별 교사 추천 발문 가이드 및 로컬 AI 후보 카드 수업 연동
  - 다크 모드(`☀️/🌙`), 전자칠판 큰 글씨 모드(`🔍 큰글씨`), 발표자 단축키(`Alt+←/→`, `Alt+T`)
  - 3단계 선택 비교 차트, 집단 응답 이동 분석표, JSON/CSV 다운로드, 클립보드 복사 및 요약 인쇄
  - 메모리 전용 개인정보 비저장 설계 및 공유 도메인(`gmlduqzhd123-lab.github.io`) 보호 규칙(`CLAUDE.md`) 준수
