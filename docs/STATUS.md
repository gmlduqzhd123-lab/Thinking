# M0 상태

- 현재 단계: M0 로컬 AI 실행 가능성 검증. 개발 전용, 모델 채택 보류.
- 확인됨: M01 초안 페이지, 실제 Worker/WASM 추론, 같은 출처 자산, SHA-256 검증, 보류 규칙, 기본 카드, 입력·취소·초기화·종료, 루트·하위 경로 브라우저 시험. 실패한 모델 준비를 시험 명령이 실패로 보고하는지 확인했고, 누락·손상·시간 초과·입력 비복원 경로를 보강했다.
- 이번 작업: 개발자 작성 가상 보류 시험 초안 60건(관련 40·보류 20)과 검수 TSV 계약, 실제 브라우저 모델을 쓰는 집계 평가 도구를 추가했다. 초안은 자동 평가에서 거부된다. `test:ai`는 개발 예시 2건의 기술 연결 시험만 통과했다.
- 남은 차단: 교사가 작성·검수한 독립 시험 60건이 없어 품질 지표는 미측정. 변환본 배포 권리 확인, 학교 PC·실물 기기 성능도 미확인.
- 다음 작업 하나: 교사가 초안 문장과 허용 탐구 집합을 검토해 독립 시험 파일을 확정한다.
- 공개 주소: GitHub Pages에는 개발 상태 안내 페이지만 게시한다. M0 앱·개발용 콘텐츠·모델 파일은 공개 배포하지 않는다. 앱 출시는 위 차단 항목이 해소될 때까지 BLOCKED다.
- Pages 실행: `main/docs` 기본 게시가 GitHub Actions 대기열에서 지연돼 전용 `.github/workflows/pages.yml`로 전환했다. 산출물은 안내용 `index.html`과 `.nojekyll`만 포함하도록 제한했다. 2026-10-20 기준 배포 실행은 queued이고 공개 URL은 HTTP 404이므로 게시 완료는 BLOCKED다.
