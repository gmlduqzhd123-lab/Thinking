# 교사 안내서

**생각의 갈림길 AI** 수업 도구 사용 안내입니다.

> [!CAUTION]
> 이 도구는 **개발 미리보기** 단계입니다. 교사 검수와 학교 기기 검증이 완료되지 않았습니다.

---

## 빠른 시작

1. 브라우저에서 수업 페이지를 엽니다.
   - **M1 기본 수업**: `lesson.html` (AI 없이 수업 흐름만 사용)
   - **M2 AI 수업**: `lesson-ai.html` (AI 후보 추천 포함)
2. 수업 시간(10분 / 20분 / 40분)을 선택합니다.
3. 참여 인원(1~60명)을 입력합니다.
4. 화면 안내에 따라 수업을 진행합니다.

---

## 수업 흐름 (10단계)

수업은 아래의 10단계로 구성되어 있습니다. 각 단계는 순서대로 진행되며, 화면 상단의 스텝 인디케이터에서 현재 위치를 확인할 수 있습니다.

| 순서 | 단계 | 이름 | 설명 |
|------|------|------|------|
| 1 | `concept` | 개념 | 단위분수 비교 개념을 소개합니다. 분수 막대 시각화로 1/3과 1/5의 크기를 비교합니다. |
| 2 | `preview` | 미리보기 | 첫 번째 문제를 미리 보여줍니다. 학생들이 답을 선택하기 전에 문제를 이해하도록 합니다. |
| 3 | `first` | 첫 선택 | 학생들의 첫 번째 답 선택을 투표로 집계합니다. 선택지는 A, B, C, D입니다. |
| 4 | `reason` | 이유 | 학생들이 왜 그렇게 선택했는지 이유 카드를 선택합니다. |
| 5 | `inquiry` | 탐구 | 탐구 카드(A: 같은 전체 나누기, B: 나누는 수 바꾸기, C: 전체 다시 만들기)를 활용하여 개념을 탐구합니다. |
| 6 | `summary` | 정리 | 탐구 결과를 정리하고 핵심 개념을 확인합니다. |
| 7 | `again` | 재선택 | 같은 문제에 대해 다시 답을 선택합니다. 첫 선택과 비교하여 변화를 확인합니다. |
| 8 | `transfer` | 새 문제 | 다른 분모 쌍(예: 1/4과 1/6)으로 전이 문제를 풀어 봅니다. |
| 9 | `memory` | 요약 | 수업 전체 결과를 요약합니다. 첫 선택 → 재선택 변화와 전이 문제 결과를 한눈에 봅니다. |
| 10 | `end` | 종료 | 수업을 종료합니다. JSON 내보내기·세션 초기화가 가능합니다. |

---

## 투표 데이터 입력 방법

"첫 선택", "재선택", "새 문제" 단계에서 학생 투표를 입력합니다.

1. 각 선택지(A, B, C, D)에 해당하는 학생 수를 숫자로 입력합니다.
2. 숫자의 합이 참여 인원을 초과하면 오류가 표시됩니다.
3. 미응답 인원은 자동으로 계산됩니다 (참여 인원 − 응답 합계).
4. 입력 완료 후 결과가 즉시 차트로 시각화됩니다.

### 입력 규칙

- 각 선택지에는 0 이상의 정수만 입력 가능합니다.
- 전체 합계는 참여 인원 이하여야 합니다.
- 참여 인원은 1~60명까지 입력할 수 있습니다.

## AI 후보 추천 (M2)

> [!IMPORTANT]
> AI 후보는 M2 수업 페이지(`lesson-ai.html`)에서만 사용할 수 있습니다.

### AI 후보란?

AI가 교사의 입력을 분석하여 가장 관련도 높은 **탐구 카드**를 "후보"로 제안하는 기능입니다.

- AI는 답을 정하지 않습니다. 후보를 **제안**할 뿐이며, 최종 판단은 교사가 합니다.
- 판단이 애매한 경우(유사도가 낮거나, 1위와 2위 차이가 작거나, 특정 패턴에 해당하는 경우) AI는 **판단 보류**를 하고 사유를 표시합니다.

### 사용 방법

1. AI 후보 패널에서 **"모델 준비"** 버튼을 클릭합니다 (최초 1회, 약 5~10초 소요).
2. 텍스트 입력란에 학생들의 일반적인 개념 혼동을 적습니다.
   - ✅ 좋은 예: `"5가 3보다 크니까 1/5 한 조각이 더 길다고 생각해요"`
   - ❌ 나쁜 예: `"김철수가 1/5이 크다고 말했어요"` (학생 이름 포함 금지)
3. **"AI 후보 요청"** 버튼을 클릭합니다.
4. AI가 추천한 탐구 카드가 표시됩니다. 판단 보류 시 사유가 함께 표시됩니다.
5. 추천이 적절하다면 **"교사 확인"** 버튼을 클릭하여 수업에 반영합니다.

### 주의 사항

- 학생 이름, 번호, 발언 원문을 입력하지 마세요.
- 최대 160자까지 입력할 수 있습니다.
- 전화번호·이메일·주민번호가 감지되면 경고가 표시됩니다 (보조 장치이며 완전한 익명화를 보장하지는 않습니다).
- AI 추론에 10초 이상 걸리면 자동 취소됩니다.

## 개인정보 보호

이 도구는 학생 개인정보 보호를 최우선으로 설계했습니다.

| 항목 | 설명 |
|------|------|
| **데이터 전송** | 없음. 모든 처리가 브라우저 안에서 이루어집니다. |
| **데이터 저장** | 없음. `localStorage`, `IndexedDB`, 쿠키를 사용하지 않습니다. |
| **외부 서버** | 없음. AI 모델은 로컬에서 실행됩니다 (`allowRemoteModels = false`). |
| **입력 필터** | 전화번호·이메일·주민번호 패턴 감지 시 경고합니다 (보조 장치). |
| **메모리** | 브라우저 탭을 닫으면 모든 데이터가 즉시 소멸합니다. |

> [!TIP]
> 수업 결과를 보관하려면 "종료" 단계에서 **JSON 내보내기** 기능을 사용하세요. 내보낸 파일은 교사의 로컬 컴퓨터에만 저장됩니다.

## 자주 묻는 질문 (FAQ)

### Q. 인터넷이 필요한가요?

**최초 설치 시에만** 필요합니다. 모델 파일을 다운로드한 후에는 오프라인에서도 사용할 수 있습니다. 수업 중에는 네트워크 연결이 필요하지 않습니다.

### Q. 어떤 브라우저를 지원하나요?

ES2022를 지원하는 최신 브라우저가 필요합니다. Microsoft Edge, Google Chrome, Mozilla Firefox의 최신 버전을 권장합니다.

### Q. AI가 잘못된 카드를 추천하면 어떻게 하나요?

AI 추천은 "후보"일 뿐입니다. 교사가 **"교사 확인"** 버튼을 클릭하지 않으면 수업에 반영되지 않습니다. 판단이 애매한 경우 AI는 스스로 "판단 보류"를 하고 사유를 표시합니다.

### Q. 학생 수가 60명을 넘으면 어떻게 하나요?

현재 버전은 최대 60명까지 지원합니다. 60명을 초과하는 경우 반을 나누어 2회 진행하는 것을 권장합니다.

### Q. 수업 결과를 저장할 수 있나요?

"종료" 단계에서 **JSON 내보내기** 버튼을 클릭하면 수업 결과가 JSON 파일로 내보내집니다. 이 파일은 교사의 컴퓨터에 로컬로 저장됩니다.

### Q. 다른 단원에서도 사용할 수 있나요?

현재는 **M01 단위분수 비교** 단원만 포함되어 있습니다. 다단원 확장 구조(`UnitConfig`)가 준비되어 있으므로 향후 새 단원이 추가될 수 있습니다.

### Q. AI 모델 준비에 시간이 오래 걸려요.

최초 모델 준비에는 약 5~10초가 걸립니다. 이후 같은 탭에서 추가 추론은 약 200~300ms로 빠르게 동작합니다. 학교 PC의 성능에 따라 시간이 다를 수 있습니다.

### Q. "판단 보류"가 너무 자주 나와요.

현재 임계값은 교사 검수 자료로 조정되지 않은 잠정값입니다. 교사 검수 60건이 수집되면 임계값을 최적화할 예정입니다.
